This program builds one fortune-cookie message for a software engineer. It keeps a single carefully chosen line, checks that the line is one line long and no more than 120 characters, then writes it to `entry.txt` so the competition can judge exactly that line and nothing else.

## Run it with python3 main.py

```sh
python3 main.py
```

By default the fortune is written to `/output/entry.txt`. Set `OUTPUT_DIR` to choose a different folder:

```sh
OUTPUT_DIR=/tmp/fortune-out python3 main.py
```
